Project Butterfly v2.5.0 - flat build (no folders)

1. Unzip this file.
2. In your GitHub repo choose Add file > Upload files and drag in EVERY file from this folder
   (say "replace" when asked). Commit.
   Also delete sea_clown.fbx from the repo if it is still there (it is no longer used).
3. Wait about a minute for GitHub Pages, then open the game once in Safari while online (it saves itself for offline play).
4. In the game: Settings > Update.
5. Full screen on iPhone/iPad: Share > Add to Home Screen. If you added an icon before, delete it first and add it again.

Offline: after the first online visit the whole game works without internet.
